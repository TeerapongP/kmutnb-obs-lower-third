# React Project Instructions

## General
- Follow the existing architecture and naming conventions.
- Read relevant code before making changes.
- Prefer small, focused changes over large refactors.
- Do not install packages without approval.
- Do not commit or push without approval.

## React
- Prefer functional components and hooks.
- Reuse existing components and utilities.
- Follow existing TypeScript or JavaScript conventions.
- Keep state close to where it is needed.
- Handle loading, error, and empty states.
- Consider accessibility and responsive layouts.

## Quality
- Add or update tests for behavioral changes.
- Run existing lint, typecheck, test, and build scripts
  when available.
- Report checks that could not run.
- Review the diff for regressions.

## pstack
- Use pstack skills when explicitly requested.
- Plan non-trivial implementation tasks.
- Show the plan before major architectural changes.
